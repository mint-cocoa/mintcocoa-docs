2 문서 구성

이 문서는 C++ 네트워크 서버 구현을 중심으로 정리했습니다. TCP Echo와 게임 서버 구현에서 시작해 io_uring 기반 Runtime, HTTP/Web 모듈, TCP Proxy 모듈, Packet Game 모듈로 책임을 나누었습니다. 클라이언트 문서는 RuntimeGame 기반 서버와 패킷을 주고받는 소비자 관점이고, DevOps 문서는 RuntimeWeb 기반 포트폴리오 서버의 배포 경로를 다룹니다.

2.2 RuntimeWeb 모듈 구현

RuntimeWeb을 서비스 앱이 아니라 HTTP 서버 선택 모듈 기준으로 분리해 설명한 문서입니다. WebServer, HttpSession, HttpParser, Router, RadixTree, HttpResponse, 파일/스트리밍 응답, timeout/backpressure 정책을 다룹니다.

2.3 RuntimeProxy 모듈 구현

RuntimeProxy를 TCP reverse proxy 선택 모듈 기준으로 분리해 설명한 문서입니다. TcpProxyServer, ProxyBridge, ProxyConnector, TLS/SNI 라우팅, ACME challenge, metrics snapshot, stream backpressure 정책을 다룹니다.

RuntimeGame을 게임 서비스 앱이 아니라 packet session과 Room 실행 모듈 기준으로 분리해 설명한 문서입니다. PacketSession, PacketBuilder, PlayerRegistry, Room, RoomManager, JobQueue 기반 Room 직렬 실행을 다룹니다.

공개 문서 노출 경로

GitHub push → GitHub Actions → docs/ render → _site/ Pages artifact → https://mint-cocoa.github.io/portfolio/

portfolio.mintcocoa.cc는 GitHub Pages custom domain이 아니라 홈랩 edge proxy 뒤의 C++ RuntimeWeb 미러입니다. 루트는 mint-cocoa.github.io 허브 앱과 같은 React/Vite 산출물을 서빙하고, 상세 문서는 같은 컨테이너의 /portfolio/ 아래에 포함합니다. Live Ops Dashboard는 GitHub Pages와 홈랩 미러 두 경로 모두에서 https://ops-api.mintcocoa.cc/api/*를 호출해 Prometheus와 Proxmox 상태를 읽습니다.
