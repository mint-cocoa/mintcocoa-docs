문서 구성의 기준

서버 구현 문서는 Core와 선택 모듈을 분리합니다. Core는 TCP 연결, 세션 수명주기, 비동기 I/O, 버퍼, 송신 큐, timeout/backpressure를 담당하고, Web/Proxy/Game은 Core 위에서 프로토콜별 의미를 추가합니다.

DevOps 문서는 mintcocoa-ops 원격 origin/main에서 확인한 구조를 기준으로 작성합니다. OKE production을 운영 기준 환경으로 두고, home k3s는 staging, 개발, 내부 도구, 복구 훈련 역할로 분리합니다. 공개 문서에는 도메인, 저장소명, 앱 이름, 커밋 해시는 남기지만 API IP, private IP, OCID, token, Secret 값은 그대로 노출하지 않습니다.
