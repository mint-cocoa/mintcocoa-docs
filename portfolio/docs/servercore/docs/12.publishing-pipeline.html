12. 포트폴리오 출판과 재현 가능한 산출물

12. Quarto와 Pages, PDF로 이어지는 문서 출판 파이프라인

1 포트폴리오 출판과 재현 가능한 산출물

마지막 단계는 구현과 운영 이력을 문서로 출판하는 과정입니다. 2026년 6월부터는 ServerCore 문서를 Quarto 기반으로 다시 정리하고, GitHub Pages와 PDF 산출물까지 연결했습니다.

날짜 커밋 증명할 수 있는 내용
2026-06-06 275c1c4 Build portfolio docs from Markdown sources Markdown 원본에서 Quarto 문서를 생성하는 파이프라인 구성
2026-06-06 de2770f Publish Quarto site to gh-pages Quarto 렌더 결과를 gh-pages로 출판
2026-06-06 ad23bde Deploy Quarto publish output to Pages GitHub Pages 배포 흐름 정리
2026-06-06 a9b59de Use Quarto listing for document index 문서 목록을 Quarto listing으로 관리
2026-06-07 492a453 Publish printable ServerCore portfolio PDF 출력용 PDF 산출물 추가
2026-06-08 75ccc83 Number portfolio document titles 문서 제목과 장 번호를 정리

1.1 현재 파일 근거

파일 역할
content/docs/*.md ServerCore와 증명 장의 Markdown 원본
content/diagrams/* 문서에서 참조하는 다이어그램 원본 자산
content/downloads/ServerCore-Portfolio-jinhoo.pdf 공개 페이지에서 링크하는 PDF 산출물
scripts/prepare-servercore-docs.js Markdown 원본을 Quarto 문서로 변환하고 index, _quarto.yml을 생성
scripts/render-docs.sh Quarto 렌더와 docs/ 산출물 검증
scripts/build-pages-site.sh GitHub Pages 배포용 _site 구성 검증

1.2 이 단계의 의미

서버 런타임 구현은 코드만으로 끝나지 않았습니다. 면접관이나 리뷰어가 읽을 수 있는 형태로 구조를 나누고, 각 장마다 실행 모델, 수명주기, 버퍼, 동시성, backpressure, 모듈 검증을 분리했습니다.

이 문서 묶음은 그 위에 추가된 증명 장입니다. Git 이력을 따라가면 포트폴리오의 주장과 실제 작업 시점이 연결됩니다.

1.3 확인 명령

git show --stat 275c1c4
git show --stat 492a453
git show --stat 75ccc83
$env:QUARTO_OUTPUT_DIR='../_tmp-docs'
node scripts/prepare-servercore-docs.js
quarto render generated-quarto

PDF 산출물까지 확인하려면 다음 명령을 사용합니다.

Get-ChildItem content/downloads
