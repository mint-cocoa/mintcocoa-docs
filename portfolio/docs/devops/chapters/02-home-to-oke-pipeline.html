2. home에서 OKE로 승격하는 배포 경계

base/overlay 구조와 수동 promotion workflow가 맡는 책임

1 같은 workload를 두 환경에 배치하는 방식

mintcocoa-ops는 home k3s와 OKE production을 같은 manifest로 직접 공유하지 않습니다. 공통 부분은 apps/<app>/base에 두고, 환경별 차이는 overlay에서 관리합니다.

apps/<app>/base
  -> apps/<app>/overlays/staging
  -> apps/<app>/overlays/prod

이 구조의 목적은 home에서 먼저 실행해 볼 수 있는 workload와 production에 공개되는 workload를 같은 앱으로 묶되, 노출 방식과 리소스 정책을 섞지 않는 것입니다.

앱 staging overlay OKE production overlay
whoami NodePort proof service ClusterIP proof service
dropapp home 검증용 NodePort public Ingress와 TLS
mintcocoa-docs 없음 docs.mintcocoa.dev production site

2 promotion workflow

production 반영은 staging에서 검증된 image tag를 prod overlay로 승격하는 workflow로 분리되어 있습니다. 이 workflow는 app 이름과 staging overlay의 image reference를 읽어 prod overlay의 image name/tag를 바꾸고, 변경 PR을 남깁니다.

단계 처리
입력 app
검증 apps/<app>/overlays/staging, apps/<app>/overlays/prod 존재 확인
변경 staging의 newName, newTag를 prod kustomization.yaml로 복사
기록 production promotion PR 생성

자동 배포가 모든 환경을 바로 바꾸는 방식이 아니라, staging 검증과 production 승격 사이에 명시적인 GitHub PR을 남기는 방식입니다.

3 dropapp에서 확인되는 환경 차이

dropapp은 C++ RuntimeWeb 기반 파일 전송 앱입니다. base에는 Deployment, Service, ConfigMap이 있고, home과 OKE overlay가 노출 경계를 다르게 둡니다.

항목 home OKE production
namespace staging-services prod-services
외부 노출 NodePort ingress-nginx
공개 도메인 없음 drop.mintcocoa.dev
TLS 없음 letsencrypt-prod ClusterIssuer
production patch 없음 resource/security policy

production overlay에는 staging보다 보수적인 resource와 security policy를 둡니다. 이 차이는 앱 코드가 아니라 OKE 실행 환경에 붙은 운영 제약이므로 overlay patch에만 남깁니다.

4 검증 workflow

gitops-validate.yml은 cluster root와 app overlay를 렌더링합니다. 이 검증은 실제 cluster에 apply하지 않고, GitOps desired state가 kustomize 단계에서 깨지지 않는지 확인하는 역할입니다.

검증 대상 예시
cluster root clusters/staging, clusters/prod
app overlay apps/whoami/overlays/*, apps/dropapp/overlays/*, apps/mintcocoa-docs/overlays/prod
shared infrastructure cluster-issuers, grafana-datasources
민감정보 패턴 private key, token, OCI key pattern

5 확인 명령

git -C /home/cocoa/mintcocoa-ops show HEAD:.github/workflows/gitops-validate.yml
git -C /home/cocoa/mintcocoa-ops show HEAD:.github/workflows/promote-staging-to-prod.yml
git -C /home/cocoa/mintcocoa-ops show HEAD:apps/dropapp/overlays/prod/kustomization.yaml
git -C /home/cocoa/mintcocoa-ops show HEAD:apps/dropapp/overlays/prod/production-resources.yaml
